# HK Fire News Archive

This folder contains all files related to the Hong Kong fire news project, which is no longer active.

## Contents

- **update_hk_fire_news.py** - Script for updating HK fire news from various sources
- **HK fire news.xlsx** - Excel file with fire news data
- **Hong-Kong-Fire-Documentary/** - Complete documentary project directory with news articles, timelines, and analysis
- **fire-news/** - Fire news web interface files
- **hk-fire-news.css**, **hk-fire-news.html**, **hk-fire-news.js** - Public-facing web files for fire news display

## Archive Date

Moved to archive on: December 26, 2025

## Status

This project is no longer active and has been archived for reference purposes.
